## 1. Chunking strategy

Implemented in `aurora_mlops/chunking.py`. Unit: One redacted support ticket (helpdesk thread or voice transcript after redaction QA).

1. Strip signatures, legal footers and auto-replies before splitting.
2. Split on speaker turns (customer / agent / system) so a question and its answer stay together.
3. Pack whole turns into chunks of at most 512 tokens (A-TRN-04); split a single over-long turn on sentence boundaries.
4. Carry the last turn of the previous chunk as overlap (one turn, bounded by the 512-token cap).
5. Fold a trailing chunk under 50 tokens into the previous chunk when it fits.
6. Attach non-PII metadata for filtering, not for embedding - topic tags, ticket close date, product category.
7. Deterministic chunk_id = hash(ticket_id, chunk_index, redaction_version), so re-runs are idempotent.

**Why:**

- Answer quality drops when evidence is buried in long context, so retrieve a few tight chunks (top-k = 5) rather than whole tickets [E-AI-03].
- 512 is the base chunk size; 256 is the alternative tested in C-AI-01 and the winner is fixed at the evaluation sign-off.

Token counting: Approximate (4 chars/token) until the embedding model is chosen; then that model's tokenizer.

## 3. Evaluation method — requires sign-off (RAG-G1)

Offline golden-set evaluation gates every release; online sampling watches production. A change to the prompt, model, chunking, embedding model or redaction version cannot ship unless every release threshold passes.

**Golden set:** 200 questions. Real retention-agent questions from the pilot, redacted. Gold chunk IDs and a reference answer per question, labeled by two retention staff; disagreements resolved by the retention team lead. Split: 160 development / 40 held-out test; the test split is only scored at release.
Refresh: Quarterly, adding at least 25 questions from production misses and new topics flagged by drift detection.

**Judge:** LLM-as-judge on faithfulness and answer relevance, using the same model tier as the assistant. Before use, the judge is scored against human labels on 100 answers; agreement must reach Cohen's kappa >= 0.7, rechecked each quarter.

- Weekly faithfulness sample below 0.95, or any confirmed PII leak, triggers the ADR-004 supersede rule (assistant off).

## 4. Drift detection

Implemented in `aurora_mlops/drift.py`.

| Signal                     | Method                                                                   | Act At                          | Action                                                      |
|:---------------------------|:-------------------------------------------------------------------------|:--------------------------------|:------------------------------------------------------------|
| Query topic mix            | Jensen-Shannon distance, this week's queries vs golden set topics        | >= 0.10                         | Add new-topic questions to the golden set; rerun full suite |
| Query embedding centroid   | Cosine distance between mean golden-set and mean weekly query embeddings | >= 0.10                         | Review sampled queries; expand golden set                   |
| Corpus topic mix           | Jensen-Shannon distance, new chunks vs trailing 90 days                  | >= 0.10                         | Check for new products or policies missing from the corpus  |
| Top-1 retrieval similarity | Two-sample KS test vs the release baseline plus median-drop guard        | p < 0.01 and median drop > 0.05 | Run full suite; consider re-index or chunk-size change      |
| No-good-match rate         | Share of queries with top-1 similarity under the release floor           | >= 15%                          | Inspect queries; add content or golden-set coverage         |
| Answer quality             | Weekly judge faithfulness on 50 sampled conversations                    | < 0.95                          | ADR-004 supersede trigger: assistant back to off            |
| Model or provider change   | Pinned model ID; any change is a release                                 | Any change                      | Full suite + red team before switching                      |
